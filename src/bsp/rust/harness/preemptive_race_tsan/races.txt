# races.txt — the cross-tier race catalogue for Lens 2 (preemptive-race-tsan): one entry per race SITE.
#
# The north-star's second invariant: state shared across tiers is owned by exactly one tier and handed over
# explicitly. Every entry here is a place the run observed that invariant broken (or a runtime intercept whose
# real site is a deeper frame). An uncatalogued site fails the gate; an entry nobody hits is reported "not seen".
#
# Fields, TAB-separated:  status  file  function-ERE  tiers  note
#   status    open       a real violation, not fixed; the note names the shared state and the owning task
#             accepted   judged benign; the note is the one-line reason. Kate reviews each one.
#             intrinsic  a bare runtime intercept (no source site); `file` is DEEP and the third field is an ERE
#                        matched against EVERY frame of the finding, naming the real site
#   file      repo-relative source path suffix, any `dir/../` collapsed
#   function  ERE matched against the SUMMARY site's function (triage.sh emits it escaped and anchored)
#   tiers     the racing tiers, from the threads' names (audio, storage, interaction, main)
#   note      the shared state (TSan's "Location is ..." line, or the variable read off the frames) and the owner.
#             TSan names the NEAREST symbol for memory inside a static arena, so "__frunk_bss_end" and
#             "HOST_INTERNAL" mean heap memory in the allocator's arena, not those symbols.
#
# Scope: the one scenario Lens 2 runs (Cordae playback while recording). Not the whole firmware.
# Rows come from triage.sh over the run logs; see the spec docs/superpowers/specs/2026-09-26-race-catalogue-design.md.
