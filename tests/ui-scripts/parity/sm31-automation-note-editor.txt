# ShellMenu: the note editor from the automation view. From the synth clip, CLIP opens the automation overview and a
# pad selects LPF FREQUENCY; SHIFT + (0,7) turns pad selection on; with a grid pad held, SELECT opens the note editor
# (NOTE EDITOR's VELO PROB ITER FILL page), not the sound menu. Then, in the note editor: the held pad's release, a
# Vertical turn, a grid press, SHIFT + a shortcut pad and a Select turn (the SELECT NOTE popup, read 100 ms after the
# turn); BACK leaves the note editor for the automation overview. No Horizontal turn: with no note under the held pad,
# main's note editor freezes on one (E379). The black encoders' first turns each drop a detent, so each turn is +2.
# Every other snapshot has a 1 s window (the pad-selection shortcut's blink). Run on the ShellMenu card.
