# ShellMenu: shortcut pads with an audition pad held inside the sound menu. From the content card's synth clip, SELECT
# opens the sound menu, and with audition pad (17,3) held the LPF frequency shortcut (8,7) jumps to the FILTER page;
# BACK leaves the menu. Then the clip is made a kit: with drum row 0 selected and its menu open, row 2 auditioned +
# (8,7) opens row 0's FILTER page (the selection stays on row 0), a turn edits row 0's LPF, BACK leaves, and SHIFT +
# (8,7) reads row 0's LPF back. Last, with row 0's menu open again, row 0 auditioned + the sequence-direction shortcut
# (4,7) opens the note-row editor on PLAY DIRECTION, the row held after the release. The script stops there: BACK
# from that editor sticks on main (its second sound editor), which is accepted as main's bug. Every snapshot has a
# 1 s window. Run on the content card with ShellMenu on (sweep-shellmenu.img).
