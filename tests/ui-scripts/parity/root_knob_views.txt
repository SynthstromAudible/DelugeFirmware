# The gold knobs at the root views: performance view, the automation view's overview, a MIDI track's CC select, a
# synth clip's note tails, an audio clip, a kit row and a kit with affect-entire, the arranger and the keyboard screen.
#
# 1 Performance view (song view, a short KEYBOARD press): mod button 1 and its knobs turned with no pad held; the
#   pad of the param a knob turns held while that knob turns (the display shows the param, no popup), and a pad
#   of the other knob's param held; mod button 6 with a stutter pad held and the upper knob pushed, then the pad
#   released. Back in the song view, mod button 0 pressed until the VU meter toggles in the sidebar: the sidebar
#   redraws only once the meter is drawn there, so it is the toggle off (vu_off) that shows a missing redraw.
# 2 Automation view overview on the boot synth clip: both knobs turned; the low-pass frequency's automation painted
#   in its editor; Learn + a knob's push copies (the lower knob's, empty, then the upper's) and Shift + Learn + the
#   lower knob's push pastes; then each knob pushed.
# 3 A MIDI clip at its root: each knob's push, held (the CC select popup shows while it is down) with turns, then
#   released, and mod button 3 pressed and released. A gold-knob turn during the hold changes nothing; the select
#   encoder turn changes the CC (alone, and with its push held), shown again on a second push.
# 4 The boot synth clip with a long note and the envelope-1 sustain at its minimum: the release knob (mod button 2,
#   lower) turned up and back down across the note-tail flip, the pads snapshot after each turn.
# 5 The same as 4 with the sound menu up.
# 6-9 An audio clip, a kit row and then the kit with affect-entire, the arranger (an output's audition pad held, then
#   the song's knobs and the VU meter), and the keyboard screen over the kit's row: in each, mod button 1 and both
#   knobs turned, each knob pushed, then mod button 0 and both knobs turned.
# 10-13 On the kit after 9: a row made from a sample (mod button 6 and both knobs); a MIDI drum and a gate drum
#   (auditioned with both knobs turned, then both knobs and mod button 2 with no audition); the clip made a synth, its
#   synth mode set to FM and back to subtractive, mod button 1's knobs turned and pushed in each; and the clip made a CV
#   clip, both knobs turned and mod button 2 pressed.
#
# The sections run in the order 4, 5, 1, 2, 3, 6, 7, 8, 9, 10, 11, 12, 13: the note tails need the boot synth clip's own
# view, the MIDI clip replaces the synth clip, the song view makes the audio and kit clips, and the last kit becomes the
# synth and then the CV clip.
