# KEYBOARD swaps the root to the keyboard screen under the menu and KEYBOARD again swaps it back. SYNC-SCALING is held
# and released (with syncScalingAction Fill it holds fill mode and lights its LED; otherwise it does nothing). BACK
# closes the menu; CLIP enters the automation view and SELECT opens the menu over it, where KEYBOARD leaves for the
# keyboard screen and KEYBOARD again returns to the automation view. SESSION leaves the menu for the session view.
