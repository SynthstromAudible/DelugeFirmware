# **How the scene gets on the stack:** `RunOptions::initial_scene`, after the fixture calls
# `slicer_scene().open(sample)`. That is the order legacy has too -- `SampleBrowser` sets
# `waveformBasicNavigator` up and *then* opens the UI (`sample_browser.cpp:652-654`, which
# `SlicerScene::open` ports) -- so the push is the second half of a real door, not a shortcut around
# one. The scene is `is_root() == false`, so nothing else on the stack is implied by it.
#
# The fixture seeds three manual slices before the run (`SlicerScene::add_slice_at`, the port of
# `slicer.cpp:535-551`), because the gesture that *adds* one is behind legacy's voice walk, which a
# spec process has no `AudioEngine` to run -- `slicer_scene_spec.cpp`'s file docstring records that
# as uncovered and seeds the table the same way, through the port's own front door.
