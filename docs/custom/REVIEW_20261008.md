# 8 October 2026 review and corrections

## Corrected issues

1. Removed the InstrumentClipView SHIFT + SELECT mode toggle. MDD mode changes only through the native OLED Sequencer menu. MDD button and encoder handlers let shifted SELECT follow stock routing; SHIFT cancels an armed MDD SELECT gesture.
2. Fixed the missing menu exit path while MDD is active. SELECT > Settings > Sequencer opens the native mode selector. BACK from the MDD main screen opens the normal clip/synth menu, retaining the playback mode. Native menu entry defers during SD card routines. The mode selector is relevant only on OLED and non-Kit instrument clips.
3. Added clip ownership for Sound's live Custom values. Closing an inactive clip using the same synth no longer clears the active clip's modulation. Closing the owner still sends note-off and clears all four sources. Null-output cleanup is safe.
4. Cloning preserves a pending mode request and the controller's song tick resolution, not just the currently active mode.
5. Extend the wrapping 32-bit sample counter before converting to milliseconds. A pad tap across sample-counter rollover no longer becomes a spurious long press. Native long-press timing now uses the exact 44.1 kHz sample rate.

## Review and regression scope

Inspected MDD mode scheduling, note/gate lifecycle, independent lane playback, UI event routing, menu access, cloning, source ownership, clip serialization, value bounds, and Plaits type/Engine plumbing. Existing stock oscillator options and the Plaits engine DSP were not changed by these corrections.

Host regression coverage: extracted native button handler, native OLED rendering, timing rollover, paths/directions/lengths/gestures/mutes/random/ranges, fractional timing, codec round trips and atomic rejection, extracted InstrumentClip note bridge, inactive-clip cleanup, retained normal play position, real Engine arithmetic, all oscillator type configurations, Envelope 1–3 destination coverage for all four Snake sources, Plaits DSP with 1000 live engine switches and A4 pitch, previous granular/delay/reverb/menu fixes and four-second OLED greeting.

ARM Release compilation and ELF-to-BIN equality are checked when packaging. Logs are included in the delivery archive. Passing these checks does not establish the absence of all firmware bugs.

## Remaining limits

No physical Deluge test was performed. OLED/pad interaction, SD file round trips, internal/external clock transitions, CPU/polyphony and audible model switching still need device testing. MDD-generated-note capture and undo integration are not implemented. Kit sequencing is not supported. The build remains experimental; the bootloader is unchanged.
