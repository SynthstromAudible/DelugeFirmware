# UI shell (`deluge_ui_shell`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the shell — surfaces, scene stack, input lowering, routing, services, tick, flush and the Deluge board profile — as a host-tested library (`src/shell`, target `deluge_ui_shell`) that drives the toolkit and `libdeluge`, ready for the scenes plan (spec E) and the harness plan (spec G) to consume. Not wired into the firmware's tick yet (that is spec F's phase 4/5).

**Architecture:** One `Shell` object owns a `SurfaceSet` (N OLED surfaces, one pad grid, one LED surface), a `SceneStack` of statically allocated `Scene` instances addressed by `SceneId`, an `InputLowering` that turns `DelugeInputEvent`s + encoder edges into `UiEvent`s through a `BoardProfile`, a routing chain (modifiers → mod-knob service → top scene → global service → drop), shell services (`Notices`, `Screensaver`, `Mirror`) and a fixed-order `tick(now_ms)`. Everything hardware-facing goes through the `SurfaceSet` interface, so the same `Shell` runs on `BoardSurfaceSet` (libdeluge) and `FakeSurfaceSet` (host canvases + recorders). Model-touching services (`GlobalControls`, `ModKnobs`, `MidiLearn`) are *interfaces* here (`Service`), implemented in the scenes plan.

**Tech Stack:** C++26, CMake, CppSpec, `deluge_ui_core/oled/grid`, `deluge_gfx_oled/grid`, `deluge_notify`, `libdeluge` C headers (`include/libdeluge/*.h`).

**Spec:** `docs/superpowers/specs/2026-08-26-ui-shell-design.md` (spec D). Read it first, then umbrella §8 (`2026-08-26-ui-stack-redesign-design.md`), and spec G §4.1 (fake surfaces). Facts about today's code the tasks port from are in `.superpowers/sdd/2026-08-26-ui-toolkit/shell-plan-facts.md` (line-numbered; if that file is gone, the tasks cite the same lines inline).

- Branch: `ui/shell` off `ui/toolkit` (stacked). "Builds" = `./dbt build Debug` compiles to the known pre-existing ThinLTO link failure (`ld.lld: error: ... Invalid record`), `cmake --build build-sim-gfx --target deluge_host` links, and the host suite is green: `cmake --build build/tests --config Debug && ctest --test-dir build/tests -C Debug --output-on-failure`.
- Layering (umbrella §rules 2–3, spec D): `src/shell/**` may include only `shell/**`, `ui/**`, `gfx/**`, `notify/**`, `libdeluge/**` (the C headers under `include/libdeluge`) and the standard library. Never `model/`, `playback/`, `processing/`, `gui/`, `hid/`, `definitions*`, `board_config.h`, `board_layout.hpp`. Task 11 adds the ratchet row `shell-includes-outside`.
- No mutable globals in `src/shell` except the one `Shell` instance the firmware will own later (not created in this plan). No heap anywhere (fixed arrays/pools). No wall clock: `now_ms` is always a parameter (spec G §5).
- Naming: `snake_case` functions/variables/members; `PascalCase` types; `k`-prefixed constants. Namespace `deluge::ui::shell`.
- Sizes (spec D): scene stack depth 8; SD-deferral queue 8 (overwrite oldest, count diagnostics); `Result::actions` capacity 8; LED entries ≤ 64 (`LedFrame::kMaxEntries`); OLED surfaces ≤ 4 (`kMaxOled`), each `128×64/8 = 1024` bytes of storage from a fixed pool; `SceneState` slot 256 bytes × `kMaxSceneKinds = 48` (open question §12.1 — measured in spec E).
- Tick order is fixed (spec D §7): drain dirty → notices → input → tick stack → OLED surfaces → grid → LEDs → next wake.
- Tests: CppSpec under `tests/spec/shell/*_spec.cpp`, registered with the same hand-spelled nested-spec exporter used by `tests/spec/ui/*_spec.cpp` (copy one); goldens under `tests/golden/ui/shell/` via `expect_golden(self, "../ui/shell/<name>.pbm", …)`; `.state` text via the fake's `state()`.
- Legacy parity: every port cites the legacy file:line in a comment; where the plan's summary and the legacy code disagree, the legacy code wins and the discrepancy is reported.
- Commit per "Commit" step; `./dbt format` first; never commit `src/bsp/rust/Cargo.lock`; never touch `src/bsp/rza1`.

  ```cpp
  template <class T, size_t N> class FixedVector {   // no heap; push_back returns false when full
  public:
  	bool push_back(const T& v) { if (n_ == N) return false; items_[n_++] = v; return true; }
  	T& operator[](size_t i) { return items_[i]; }  const T& operator[](size_t i) const { return items_[i]; }
  	size_t size() const { return n_; }  bool empty() const { return n_ == 0; }  void clear() { n_ = 0; }
  	T* begin() { return items_; }  T* end() { return items_ + n_; }  const T* begin() const { return items_; }  const T* end() const { return items_ + n_; }
  private: T items_[N]{}; size_t n_ = 0; };

  	std::span<const EncoderRole> encoder_by_index;   // libdeluge encoder index -> role
  ```

```cpp
void SurfaceSet::build(const DelugeBoard& b, const BoardProfile& p) {
	oled_count_ = std::min<uint8_t>(b.display_count, kMaxOled);
	for (uint8_t i = 0; i < oled_count_; i++) {
		const DelugeDisplayDesc& d = b.displays ? b.displays[i] : DelugeDisplayDesc{b.display_width, b.display_height, 0};
		gfx::oled::Geometry g{d.width, d.height, d.visible_top};
		new (&oled_[i]) OledSurface{gfx::oled::Canvas(std::span<uint8_t>(storage_[i], kOledStorageBytes), g), g, RepaintGate{},
		                             i < p.oled_role_by_index.size() ? p.oled_role_by_index[i] : SurfaceRole::None, i,
		                             /* blit_pending */ false,
		                             i < p.style_by_index.size() ? p.style_by_index[i] : nullptr};
	}
	const uint8_t main_cols = b.pad_grid_width > 2 ? b.pad_grid_width - 2 : b.pad_grid_width;   // see the descriptor note above
	grid_.grid_storage.emplace(gfx::grid::GridDimensions{main_cols, uint8_t(b.pad_grid_width - main_cols), b.pad_grid_height});
	grid_.pairs = b.pad_grid_width / 2;
}
```

```cpp
void Shell::tick(uint32_t now_ms) {
	const uint32_t dt = now_ms - last_ms_;
	const notify::DirtySet dirty = notify::dirty().drain();
	apply_dirty(dirty);                                   // on_model_changed on every stacked scene; gates: Oled -> all oled gates; GridMain/GridSidebar/ClipContent/NoteRows -> grid gate; PlaybackState/… -> all
	notices_.drain(notify::notices(), now_ms);
	pump_input(now_ms);                                   // begin_tick (incl. lowering_.ctx().begin_tick(now_ms)); while lowering_.next(e): route the five ordinary shapes through router_.route(e, ctx), stash the six widget-owned shapes (§4's list) into held_back_ instead; end_tick; had_input_ = lowering_.had_input_this_tick()
	tick_stack(dt);                                       // top-down; stop below the first occludes_grid(); services tick
	if (stack_.changed_since_last_query()) { greyout_ = union of greyout_mask() over the stack; request_repaint on every gate; }
	rendered_this_tick_.clear();
	for (auto& s : surfaces_.oled()) if (s.gate.needs_frame(now_ms, had_input_, dirty.any()) || lowering_.ctx().gate.needs_frame(now_ms, had_input_, dirty.any()) || router_.repaint_requested(s.role)) { render_oled(s); s.blit_pending = true; }
	auto& g = surfaces_.grid(); if (g.gate.needs_frame(now_ms, had_input_, dirty.any()) || lowering_.ctx().gate.needs_frame(now_ms, had_input_, dirty.any())) { render_grid(now_ms); grid_dirty_ = true; }
	for (auto* scene : rendered_this_tick_) router_.apply(scene->after_render());     // navigation from this tick's Responses (§3)
	deliver_post_render_input(now_ms);                                                // held_back_, each gated by lowering_.ctx().claims (below)
	derive_leds(now_ms);
	flush(now_ms);                                        // Task 8
	router_.clear_repaint_requests();
	last_ms_ = now_ms;
}
```
