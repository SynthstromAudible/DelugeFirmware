The shape of the attack, decay and release of the currently selected envelope.

0 is linear. Positive values are exponential: each stage moves fastest at its start, like an analog envelope.
Negative values bend the other way, moving slowly at first. The default, 32, is the shape Deluge envelopes have always
had. The attack is bent half as much as the decay and release.

In AR mode, positive values approach the target exponentially and 0 or below moves towards it in a straight line.
