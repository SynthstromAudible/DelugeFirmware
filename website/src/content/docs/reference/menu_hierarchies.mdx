This document will document the menu structure hierarchy currently in place in the deluge in order to help users understand what exists in the menu structure and how the hierarchy strings are defined for OLED and 7SEG users.

By default, the hierarchies below show the OLED display text first, followed by the 7SEG display text.

## Settings

<details>
<summary>Settings Menu</summary>
The Settings menu is accessible from anywhere on the Deluge by pressing :key[SHIFT] + :key[SELECT]. It is used for configuring default settings that persist after the Deluge has been turned off.
