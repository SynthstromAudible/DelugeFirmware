Arranger view is a powerful persona and view within Deluge. Understanding the basics is important to get started. More advanced functions also exist to integrate tightly with session view and align common functions such as song and clip playback.

<StepFocus />

## Opening clips in arranger directly from session view

<Steps>

1. Select session view :key[Song], button is lit solid blue.
2. Press & hold :key[Pad], the clip row to drag to arranger + press :key[Song].
3. The view will switch to arranger.
4. While still holding the :key[Pad] in arranger view, :key[Turn Horizontal] to locate the position to a column across the instrument row.
5. Release :key[Pad] to drop the clip instance in the arranger grid.

</Steps>

## Opening clips in session view directly from arranger

<Steps>

1. Select arranger view :key[Song], :key[Song]. Button flashes blue.
2. Press & hold :key[Pad], the clip instance to drag to session view + press :key[Song]. The typical use would be to drag over a white clip, which by default doesn't exist in session view.
3. The view will switch to session view.
4. While still holding the :key[Pad] in session view, :key[Turn Vertical] to locate the position within the clip rows.
5. Release :key[Pad] to drop the clip into the song grid row position.
6. Once in session view, the clip will change from white to an assigned section and its associated colour. This colour will now be reflected in the clip instance in arrangement view.

</Steps>

## Synchronising playback between views

<Steps>

1. In arranger view:
   1. Press the dimly lit :key[Pad] clip ‘tail’, not the left most bright pad, which will switch to clip view.
   2. Pressing :key[Play] after entering clip view this way will start playback in the arranger from the beginning of this clip instance.
2. In arranger view:
   1. Press :key[Play] to play back the arrangement.
   2. Switch to session view :key[Song], button lit solid blue.
   3. The pads will be lit slightly dim while arranger controls the transport playback.
   4. Control can be regained within the session mode. Sections and clips can be triggered in session mode which override the arranger.
3. In session view:
   1. Press :key[Play].
   2. Press :key[Song] which will switch to the arranger view.
   3. :key[Turn Horizontal] to set the playback start position in the arranger view.
   4. Press & hold :key[Horizontal + Play] to start arranger playback from the new position once the song loop completes.

</Steps>
