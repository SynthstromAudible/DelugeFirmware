An optional way of presenting the session mode is to use the grid view. Generally speaking this still offers the same core session mode functionality but is presented with a grid style as opposed to a row view and the play and edit modes need to be selected. The functions in row or grid view are generally the same but with some visualisation and application differences.

Deluge will only play one instrument at one time in session view. So for example, if two clips use the same synth preset 1 or clone of 1, the clip rows can each be launched but each one will stop playback of the other, allowing only one instance of each instrument to play at one time.

<StepFocus />

## Playing a song grid pattern

<Steps>

1. Press :key[Song] to switch to session view. The button illuminates blue. If this is a new song and the first this time the session mode is selected, the song may be empty or only show the first clip compressed to the first row.
2. Hold :key[Song + Turn Select] to change between song row and grid view. Select Grid view.
3. Press :key[Play] to playback the song.
4. The grid of pads represents consolidated clips and sections. Only the first clip in a section is visible on a pad. Track column colours are randomly generated.
5. Press :key[Play] to stop and reset playback position to the song start.

</Steps>

## Selecting an existing clip to edit from session grid view

<Steps>

1. Press :key[Song] to switch to session mode. The button illuminates blue. Press :key[Song + Turn Select] to switch to grid view.
2. Press the blue :key[Audition Pad] to select pad edit, blue mode.
3. Press a :key[Pad] of any occupied row from the 16 x 8 main grid. The occupied pads containing clips will be illuminated fully or in part.
4. Deluge transfers the view from song to clip view ready to edit.
5. Any edits, steps created etc in the clip will be reflected when switching back to :key[Song] view.

</Steps>

Note: Overdub recording and copying clips is not supported in Session Grid View. These functions should be performed in the default session row view.

### Launch Control of Single Clips in Session Grid View

More advanced options are available in session grid view than just the start stop commands for individual clips. Clips are armed to ensure the timing of the clip start aligns with the overall song.

<Figure
  id="fig-12.4-2"
  src={fig_fig_12_4_2}
  alt={
    "Diagram: [LAUNCH] Mute / launch column pad enables the arming and triggering of clip sections in time with a playing song. To launch clips GREEN…"

Display shows countdown of loops to complete when a clip row is ‘armed’ and launching or stopping clips, default is 1. To increase the loops to play prior to launch / stop, :key[Turn Select] to change the loop countdown.

Press :key[Select] to cancel loop countdown.

Press :key[Shift + Launch Pad] to immediately play the clip row in session view.

## Launching / stopping a clip or section in session grid view

<Steps>

1. With the sequencer playing, Press :key[Pad] to launch a clip. A clip pad will flash to signify it is armed and at the appropriate time will launch the clip playback.
2. With the sequencer playing, Press :key[Launch Pad] to launch a clip section. The associated clip pads will flash to signify they are armed and at the appropriate time will launch the all clip playback.
3. If the clip was already playing it will be armed to stopped.
4. Playing clips are lit bright and clips which are stopped are lit dimmed.

</Steps>

## Adjusting armed countdown on the fly

<Steps>

1. When a clip is armed to launch or to stop it will flash. Clips which are not playing are dimmed and those playing lit bright. During this time the display will show a countdown number that signifies a full or part loop to complete prior to launch / stop.
2. While the number is displayed, :key[Turn Select] to adjust the number of the loop countdown - increasing or reducing the wait timer to trigger the launch / stop command.
3. While the number is displayed, press :key[Select] to clear the countdown timer and clear arming of the clip.

</Steps>

## Soloing clips in session grid view

<Steps>

1. To solo a clip, press & hold :key[Horizontal + Pad] of clip to toggle solo on or off.
2. If the sequence is playing the solo request will be ‘armed’ to solo on the next repeat cycle. Pad will flash when armed.
3. Other clips of course will be muted and these will be extra dimly lit.
4. To solo immediately without arming, press & hold :key[Shift + Horizontal + Pad] to toggle solo on or off.

</Steps>
