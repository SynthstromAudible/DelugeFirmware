Stutter is a general system effect that is only available for control through the affect parameters and is not available in the nested parameter set nor by the shortcut grid.

### Setting up stutter

1. Select :key[Kit], or :key[Synth], etc,
2. Press :key[StutterCustom1]. Button lit orange.
3. :key[Turn Upper Gold] to select the stutter length and speed.
4. Press & :key[Turn Upper Gold] to adjust a short stutter length and speed while triggering.

### Using stutter

1. Select :key[Kit] or :key[Synth], etc...
2. :key[Play] the song.
3. Press :key[StutterCustom1]. Button lit orange.
4. Press :key[Upper Gold] to trigger the stutter effect.
5. Release :key[Upper Gold] to stop the stutter effect.
6. Press & :key[Turn Upper Gold] to adjust a short stutter length and speed while triggering.
