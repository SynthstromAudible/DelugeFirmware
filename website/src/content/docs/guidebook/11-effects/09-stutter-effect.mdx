Stutter is a general system effect that is only available for control through the affect parameters and is not available in the nested parameter set nor by the shortcut grid. The option to adjust the stutter quantized values is possible if the STUTTER RATE QUANTIZE option is set to ON in the community features menu in the settings.

<StepFocus />

## Setting up stutter

<Steps>

1. Select :key[Kit] or :key[Synth] etc…
2. Press :key[StutterCustom1]. Button lit orange.
3. :key[Turn Upper Gold] to select the stutter length and speed. The option to adjust in quantized 4ths, 8ths, 16ths, 32nds or 64ths is available if set ON in the community feature settings.
4. Press & :key[Turn Upper Gold] to adjust a short stutter length and speed while triggering.

</Steps>

## Using stutter

<Steps>

1. Select :key[Kit] or :key[Synth], etc...
2. :key[Play] the song.
3. Press :key[StutterCustom1]. Button lit orange.
4. The selected value is centre on the :key[Upper Gold] control and can deviate up or down when turning the encoder and return to original by centring the encoder.
5. Hold :key[Upper Gold] to trigger the stutter effect.
6. Release :key[Upper Gold] to stop the stutter effect.
7. Press & :key[Turn Upper Gold] to adjust a short stutter length and speed while triggering.

</Steps>
