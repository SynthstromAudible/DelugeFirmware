Affect parameters are used for effect adjustments in session view. When selecting song :key[Song] view it first appears that the affect parameters are not available. However they are accessible by pressing and holding :key[Pad] in SESSION mode.

<StepFocus />

## Accessing effects in session mode

<Steps>

1. Press :key[Song]. Button illuminates solid blue.
2. Press & hold :key[Pad], where pad is any pad row with an active clip. This enables access to changing the parameters for the CLIP.
3. Press :key[AffectEntire]. Button illuminates orange.
4. The affect parameters are now accessible for the entire SONG. The associated buttons and UPPER / LOWER controls can be adjusted.
5. Parameters available by default in session view are:
   - Mod-FX
   - EQ
   - Delay
   - Reverb
   - Stutter
   - Bitcrush / decimation (custom 2 & 3)

</Steps>
