The Deluge can be controlled by external MIDI keyboards, controllers or pads by mapping incoming MIDI to the desired notes, pads or parameters. Velocity is recorded with MIDI inputs. Note that the isomorphic, in-key and norms pad views can show incoming notes and velocity by brightness if set up as such in the community settings options.

<StepFocus />

### Setting up an external keyboard or pads

<Steps>

1. Connect the keyboard MIDI-out to the MIDI-in connection of Deluge. Power both devices on.
2. Press :key[Synth], :key[Kit] , :key[CV] or :key[MIDI] to select the instrument clip. Button selected illuminates red.
3. Press & hold :key[LearnInput + Audition Pad] of a note / pad to map.
4. While holding :key[LearnInput] & :key[Audition Pad], press a keyboard note on the external keyboard or the pad on the external controller.
5. The audition pads will blink and turn pink or a brighter colour when a mapping input is set.
6. The MIDI channel plus the external keyboard notes will now be mapped to the Deluge. Pitch bend and mod wheel (mapped to Y axis) on the external midi controller keyboard will also function.
7. To unmap the keyboard press & hold :key[LearnInput + Audition Pad] any pad.

</Steps>

### Setting up an external controller

<Steps>

1. Connect the controller MIDI-out to the MIDI-in connection of Deluge. Power both devices on.
2. Press :key[Synth], :key[Kit], :key[CV] or :key[MIDI] to select the instrument clip. Button selected illuminates red.
3. Select the parameter to map to. Press :key[Shift + Pad], where pad is the parameter to map. Example LPF frequency.
4. The pad will flash white indicating it is selected and the display reflects this parameter.
5. Press & hold :key[LearnInput]. Parameters that can’t be mapped will display a notification.
6. While holding :key[LearnInput], adjust the control on the external device to map to the selected parameter.
7. Display will indicate mapping is complete by displaying ‘LEARNED’.
8. MIDI channel plus the external control is now be mapped to the Deluge.
9. The behaviour of the Deluge parameter from of the external controller will be dependant on the MIDI Takeover setting in the MIDI options.
10. To unmap the keyboard press & hold :key[Shift + LearnInput] while the parameter is selected, indicated by its flashing pad. +

</Steps>

#### MIDI Takeover Mode.

MIDI takeover mode, selectable in the MIDI settings governs the way an external CC parameter control is applied to a Deluge parameter. The behaviour of the Deluge parameter can operate in one of 3 modes when the external control is adjusted. The externally connected MIDI controller will then operate the mapped Deluge parameter based on this mode.

### Setting up MIDI takeover mode

<Steps>

1. Hold :key[Shift + Select].
2. :key[Turn Select] and highlight the ‘MIDI’ option in the menu.
3. Press :key[Select] to select the MIDI option.
4. Within the MIDI Sub-menu, highlight ‘TAKEOVER’ by turning :key[Select].
5. Press :key[Select] to select the ‘TAKEOVER’ option.
6. :key[Turn Select] to choose one of the takeover sub-menu options:

</Steps>

<FigurePending id="fig-12.3-3" page={274}>

### Recording automation using an external controller

<Steps>

1. Set up an external MIDI controller, whether a keyboard or pad or rotary / slider controls and map the incoming MIDI to the parameters desired.
2. Press :key[Record] to arm recording.
3. Press :key[Play] to start recording.
4. Any incoming MIDI that is relevant to the clip being recorded will be recorded in including automation of parameters and velocity. Example, changing a control mapped to frequency cutoff will record in as automation. Assignment of gold affect controls is irrelevant.
5. Parameters containing automation will display their name with a full stop / period / dot next to them when assigning a parameter knob’s MIDI parameter. This indicates automation is present.
6. Press :key[Play] to stop.
7. To delete MIDI in recorded automation, re-start recording and press :key[Shift] and adjust the mapped external controller.
8. Parameters containing automation will display their name with a dot next to them when assigning a parameter knob’s MIDI parameter - so it will be easy to see where automation exists.
9. Assigning a new MIDI parameter to a parameter knob does not move the knob’s automation over to the new MIDI parameter. Automation can be manually copied and pasted using the normal manual process.

</Steps>

:::note
Any recorded data for pitch bend and aftertouch (channel pressure) MIDI inputs is captured in MIDI, Synth or CV clips and is retained with the clip even when changing presents or clip types. Also note-off velocity, if delivered by an external controller will be recorded.
:::
