As well as samples, sounds, synths, MIDI can also be combined within a kit as a row providing a note or control output to a MIDI channel. MIDI sequencing can then take place alongside other kit sounds. Song specific MIDI commands are saved with the song. Global settings remain unchanged.

<StepFocus />

### Creating / converting to MIDI within kit clips

<Steps>

1. Select :key[Clip] view and select a :key[Kit].
2. Press & hold :key[Audition Pad] for the row which will convert to MIDI + press :key[MIDI].
3. Hold :key[Audition Pad] for the MIDI row to display the channel and note information, each separated by a dot.

</Steps>

<Steps>

4. While holding the audition pad, :key[Turn Lower Gold] control to change the MIDI channel.
5. While holding the audition pad, :key[Turn Upper Gold] control to change the note value.
6. :key[Kit + Save] to save the kit and retain the MIDI setting in the kit.

</Steps>

### Changing clip MIDI channel within song view

<Steps>

1. Select :key[Song] view.
2. Press & hold :key[Pad] for the MIDI clip row to change + :key[Turn Select] to change channel 1-16.
3. MIDI button will flash while holding and display will show the current channel.

</Steps>
