## Supersaw <Badge text="C1.4" variant="tip" />

The supersaw plays a stack of up to eight detuned sawtooth waves from a single oscillator. As the saws drift in and out of phase with each other they give the thick shimmering sound heard in trance leads, lush pads and big saw basses.
Select SUPERSAW in the oscillator TYPE menu, just after ANALOG SAW (SSAW on 7SEG).

Two oscillator settings take on new jobs when the type is supersaw:

- **Spread** is set with :key[Wavetable Pad]. At 0 the saws are all in tune. Turning it up detunes them further apart and brings the outer saws up in the mix. Spread can be automated or modulated like any other parameter.
- **Number of saws** is set with :key[Pulse Width Pad]. At 0 all seven saws play. Turning it up removes them one at a time

The volume stays about the same when the spread or the number of saws changes so either one can be adjusted freely while playing.

With RETRIGGER PHASE set every saw starts from the same phase. This makes the attack punchier since they'll all add with no phase cancellation at the beginning.

See also [Supersaw Oscillator](/features/community_features#4513---supersaw-oscillator) in the Feature Overview.

### Setting up a supersaw

<Steps>

1. Press :key[Clip] to select clip view. This is indicated by the clip button illuminated blue.
2. Select synth by pressing :key[Synth] if not already selected. The synth button illuminates red.
3. Press :key[Shift + Type Pad] for OSC 1 or 2. Alternatively use the nested menu options by pressing :key[Select] and navigating to ‘TYPE’.
4. Turning :key[Select] navigates the waveform options. Select SUPERSAW.
5. Press :key[Shift + Wavetable Pad] for the same oscillator and turn :key[Select] to set the spread. Play some notes on the audition pads while turning to hear the saws move apart.
6. Press :key[Shift + Pulse Width Pad] and turn :key[Select] to set the number of saws. Leave it at 0 for the full seven.
7. For an even wider sound, add unison voices with some UNISON STEREO SPREAD, or a little chorus. Patch an LFO or envelope to WAVE-INDEX to make the spread move.

</Steps>

## Using a sample as an oscillator waveform source

<Steps>

1. Press :key[Clip] to select clip view. This is indicated by the clip button illuminated blue.
2. Select synth by pressing :key[Synth] if not already selected. The synth button illuminates red.
3. Press :key[Shift + Type Pad] as quick access shortcut for OSC 1 or 2. Alternatively use the nested menu options by pressing :key[Select] and navigating to ‘TYPE’.
4. Turning :key[Select] navigates the waveform options. Select SAMPLE.
5. Use :key[BackUndo] to exit sub-menu and back up a level. A new set of parameters, made available by selecting the SAMPLE option are now accessible.
6. Select a sample by navigating to ‘FILE BROWSER’ by turning :key[Select].
7. Pressing :key[Select] while FILE BROWSER is in focus opens the option to browse and select a sample, ‘BOTTOM-TO-TOP’ will appear on the display to indicate the bottom-to-top note range.
8. Press :key[Select] to enter the sample browser. By default the factory folders for ARTISTS, DRUMS, RECORD, RESAMPLE are available which can be selected by turning and then pressing :key[Select] when the folder is in-focus.
9. Navigate samples and folders by turning :key[Select]. The sample will audition and an illustration of the sample will be mapped across the grid.
10. Press :key[Select] to load the sample as the oscillator wave.

</Steps>
