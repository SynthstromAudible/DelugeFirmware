## Selecting a synth preset

<Steps>

1. Press :key[Clip] to select clip view. This is indicated by the clip button illuminated blue.
2. Press :key[Synth] button to select synth. Synth button illuminates red.
3. Rotate the :key[Select] rotary control to select a synth preset. The selected preset is indicated by the number or name on the display.
4. Press an :key[Audition Pad] to listen to the sound and the note played. This enables auditioning of the sounds for selection.
5. Once selected, the sound displayed will be ready for use on the current clip. Synth presets are only the instrument - not a pattern.

</Steps>

## Selecting a kit preset

<Steps>

1. Press :key[Clip] to select clip view. This is indicated by the clip button illuminated blue.
2. Press :key[Kit] button to select a kit. Kit button illuminates red.
3. Rotate the :key[Select] rotary control to select a kit preset. The selected preset is indicated by the number on the display.
4. Press an :key[Audition Pad] up / down the pad row plays out each sound from the kit collection. This enables the auditioning of the individual sounds on each row prior to selection.
5. Once selected, the sound displayed will be ready for use on the current Clip. Kit presets are only the kit instrument and sounds / samples - not a pattern.

</Steps>

## Selecting a synth preset with selection menu

<Steps>

1. Press :key[Clip] to select clip view. This is indicated by the clip button illuminated blue.
2. Select synth by pressing :key[Synth] if not already selected. The synth button illuminates red.
3. Press :key[Load + Synth] to open the load menu.
4. The alphanumeric keyboard will appear to enable searching for a preset name or :key[Turn Select] to choose a preset.
5. Press an :key[Audition Pad] to listen to the sound and the note played. This enables auditioning of the sounds for selection.
6. Press :key[Load] to load the preset.
7. Once selected, the sound displayed will be ready for use on the current clip. Synth presets are only the instrument - not a pattern.

</Steps>

## Saving a synth preset in clip view / keyboard view

<Steps>

1. To save current preset sound, press :key[Save + Synth]. The buttons SAVE, SYNTH and BACK/UNDO plus the display will flash.
2. The display will indicate the next available iteration of patch number i.e patch 171, if patch 171 exists, Deluge will show 171A, then 171b etc. This avoids accidentally overwriting existing patches. Turning :key[Select] allows the option to select existing patch to overwrite.
3. The alphanumeric keyboard appears to allow a preset name to be entered.
4. Press :key[Save] button to confirm saving or press :key[BackUndo] to cancel. A PRESET SAVED message will be displayed when complete.
5. The patch is stored in the SYNTH folder on the SD card, named by the patch number selected i.e. for patch 171A: SYNT171A.XML.

</Steps>

## Saving a kit preset in clip view

<Steps>

1. To save current kit, Press :key[Save + Kit]. The buttons SAVE, KIT and BACK/UNDO plus the display will flash.
2. The display will indicate the next available iteration of patch number i.e kit 0, if kit 0 exists, Deluge will show 0A, then 0b etc. This avoids accidentally overwriting existing patches. Turning :key[Select] allows the option to select an existing kit to overwrite.
3. The alphanumeric keyboard appears to allow a preset name to be entered.
4. Press :key[Save] button to confirm saving or press :key[BackUndo] to cancel. A message will be displayed when complete.
5. The kit is stored in the KIT folder on the SD card named by the kit number selected i.e. for kit 0A; KIT000A.XML.

</Steps>

:::note
Any new presets saved are available in the library for selection when loading. This means the numbering may vary from the listed factory library i.e. instead of the original kits 3, 4, 5, 6 for example the list may now read 2, 3, 4, 4A, 4b, 5, 6 as well as the manually named presets.
:::

## Creating a preset folder

<Steps>

1. Press :key[Clip] to select clip view. This is indicated by the clip button illuminated blue.
2. Press :key[Synth] or :key[Kit] button to select.
3. Press :key[Save + Synth] or :key[Kit] to open the save menu.
4. The alphanumeric keyboard will appear. Type a name of the folder to create.
5. Press and hold :key[Save] until CREATE FOLDER appears.
6. Press :key[Save] to create the folder. This folder will be visible when loading and also will be available to save presets.
7. If required, type in the preset name or number to save or press :key[BackUndo] to exit.

</Steps>

## Checking the instrument for a clip

<Steps>

1. Press :key[Song] to switch to session view. If in Session grid view the blue edit mode will need to be active.
2. Press & hold a :key[Pad] within the clip to check.
3. While still holding, the instrument button will flash indicating the type selected and the display will show the instrument preset. For example synth, preset SYNT001
4. Affect parameters for the clip also become available and in-focus.
5. Holding a clip in an empty clip row will show the instrument type and preset that it will create when tapping the clip row.

</Steps>

## Changing the clips instrument from session view

<Steps>

1. Press :key[Song] to switch to session view. If in Session grid view the blue edit mode will need to be active.
2. Press & hold a :key[Pad] within the clip to change.
3. While still holding, select the instrument type, example :key[Synth], :key[Kit].
4. While still holding, select the instrument preset by turning :key[Select].
5. Holding a clip in an empty clip row will also allow changes to be made.

</Steps>

## Changing a tracks preset when in arranger view

<Steps>

1. Press :key[Audition Pad] to hear the instrument / sound for the row.
2. Press & hold :key[Audition Pad] for the instrument / row to change + :key[Select] to scroll the presets.

</Steps>

or

<Steps>

2. Press & hold :key[Audition Pad] for the instrument / row to change + track type :key[Synth], :key[Kit], :key[MIDI], :key[CV].

</Steps>

or

<Steps>

2. Press & hold :key[Audition Pad] for the instrument / row to change + press :key[Select] for an audio track.

</Steps>
