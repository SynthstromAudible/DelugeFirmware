## Adjusting a synth clip colour

<Steps>

1. Press :key[Synth]. The button illuminates red.
2. Press & hold :key[Shift + Turn Vertical].
3. Colour will change as the :key[Vertical] is adjusted. Release control and buttons when the colour is selected.

</Steps>

## Changing a clip row colour

<Steps>

1. Press :key[Song] to switch to session view. If in Session grid view the blue edit mode will need to be active.
2. Press & hold a :key[Pad] + hold :key[Shift + Turn Vertical].
3. The clip row colour will be adjusted.

</Steps>

## Changing a clip colour

<Steps>

1. Hold :key[Pad] for any active clip in the column + :key[Turn Vertical].
2. The colour of the instrument column can be adjusted as required.
3. Note that this process in Session row view will re-order rows.

</Steps>
