A dedicated and complimentary parameter automation view is available within clip mode. Consider this as a pattern automation layer per parameter overlaid over the Instrument Clip View for Synths, Kits and Midi instrument clip types.

The audition sidebar button for the instrument clip types is available in the automation Instrument clip view so that you can previews sounds while viewing/editing parameter automations. The behaviour of these buttons is configurable in the settings &gt; community features.

<StepFocus />

### Selecting parameter automation view

<Steps>

1. Press :key[Clip] button to cycle through the normal or automation views.
2. The :key[Clip] button will flash blue when automation view is selected. The display will also state ‘AUTOMATION OVERVIEW’.

</Steps>

When moving from Automation Instrument Clip View to Song/Arranger View, the Deluge will remember the state on a per Instrument Clip basis. This means that transitioning back to an Instrument Clip will re-load the Automation Instrument Clip View if previously in that view. This information is saved with the song.

You can load up the Keyboard Screen while in the Automation Instrument Clip View so you can quickly switch between editing a Parameter and playing notes on the Keyboard.

Automation settings are saved per Instrument per Clip with the Song

Automations that are recorded using the Gold :key[Upper Gold] and :key[Lower Gold] Mod Encoders and are always recorded with Interpolation.

Automation can be recorded live.

MPE automations are not covered/edited by this Automation Instrument Clip View. If MPE must be edited/nudged/shifted, it must be done in the current Instrument Clip View.

### Selecting a parameter to edit in automation view

<Steps>

1. Select Automation View. Press :key[Clip] button until it flashes blue.
2. Select a parameter to edit. Only the parameters available to automate are accessible.
   - :key[Turn Select] to cycle through the parameters to select.
   - Alternatively, Hold :key[Shift + Pad] to select the parameter to edit from the available automation parameters.
   - The default ‘AUTOMATON OVERVIEW’ may be on show and the pads lit white which contain the available parameters to automate. Bright white contains automated parameters while dimmed will not be automated. Tap the :key[Pad] for the selected parameter to edit. This mode is may change when selecting and editing instruments and parameters as the previous view is restored when navigating from / to automation.
3. Once the parameter is selected and shown on the display, its automation can be edited. The current state i.e. ‘NOT AUTOMATED’ vs ‘AUTOMATED’ is displayed along with the parameter name and value.
   - :key[Turn Upper Gold] or :key[Lower Gold] knob to adjust the parameter equally across the step range. General parameters operating over a 0-50 displayed range which in reality represents the 0-128 of the parameter value. Pads illuminate to show the value per step.
   - To use Pads for automation creating and editing.
   - Press :key[Upper Gold] or :key[Lower Gold] to toggle the ‘Pad Selection’ mode On or Off. Set to Off to edit automation by pressing pads.
   - Press / Slide across the :key[Pad] grid buttons. The profile of the pads selected represents the shape of automation curve applied to the parameter across the pattern. Pads illuminate to show the value per step in the pad columns.
   - To enter a long multi-step automation slope across a column range, Hold :key[Pad] as the start point while pressing another :key[Pad]. An automation shape is applied with values interpolated between the selected start ‘L’ and end ‘R’ :key[Pad]’s
   - To adjust an individual pad column value from the current value, hold the upper :key[Pad + Turn Upper Gold] or :key[Lower Gold].

</Steps>

Additional Automation View Notes

- Settings to delineate behaviour from the associated Note patterns is provided in the Settings &gt; Community Features.
- Interpolation is can be set on and off for manually edited automation. Recorded automation is always recorded with interpolation on.
- The Automation Editor will not allow you to:
  - Access the regular settings menu
  - Access the sound editor
  - Access the sample browser
  - Use regular grid shortcuts (except for shift + param)
  - Edit MPE parameter values
  - Edit existing synth note row values (e.g. change a pad from F to F#)
  - Edit existing note row sounds in a kit (e.g. change the sample)
  - Add new rows in a kit
  - Re-arrange rows in a kit
  - Change root note in a synth/midi/cv clip
