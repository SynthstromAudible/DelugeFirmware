Deluge has a number of features that bring even more creativity to sequencing. Note probability and iteration dependance is a feature which uses logic to determine if the note plays on the sequence cycle or not and adds randomness.

#### Probability

<StepFocus />

### Setting a note probability to add randomness

<Steps>

1. Press & hold one or more :key[Pad + Turn Select] anticlockwise. The pad’s selected should represent the sequence notes of where to add probability.
2. Adjust the :key[Select] percentage between 5-100% where the % is the ‘chance’ of the note being played.
3. To reset to default set the % to 100% where the note will be played each iteration.
4. To assign a probability for an entire pad row, Hold :key[Audition Pad] for row to edit + :key[Turn Select] anticlockwise.

</Steps>

#### Iteration Dependance

### Setting a note iteration dependance

<Steps>

1. Press & hold :key[Pad + Turn Select] clockwise. Pad selected should represent the sequence note of where you intend to add the iteration.
2. Adjust the :key[Select] setting to one of the settings between ‘1 of 2’ up to ‘8 of 8’.
3. The ratio represents when the note plays for every iteration (bar) that the sequencer plays. So ‘1 of 2’ plays the note on the 1st of every 2 bars, ‘3 of 4’ plays on the 3rd of each 4 rotations. 1 of 2 - Play on 1st of 2 bar cycles

</Steps>

#### Fill

Fill is a specific probability / iteration function which allows punch in/out performance variations of notes into musical passages ideally during live performances. Fill is triggered manually or with the global MIDI commands. Either of these options must be configured in the settings.

### Configuring the manual fill option

<Steps>

1. Hold :key[Shift + Select] to open the global menu settings.
2. :key[Turn Select] to navigate to the ‘COMMUNITY FEATURES’. Press :key[Select] to open the sub-menu.
3. :key[Turn Select] to navigate to the ‘SYNC SCALING ACTION’. Press :key[Select] to open the sub-menu.
4. :key[Turn Select] to navigate to the ‘SYNC SCALING’ or ‘FILL MODE’. Press :key[Select] to select the desired option:
   - SYNC SCALING: Will configure the SYNC-SCALING button to operate in the default state i.e. control sync scaling.
   - FILL MODE: Will configure the SYNC-SCALING button to operate the manual FILL function.

</Steps>

### Configuring the MIDI fill option

<Steps>

1. Connect a foot switch or MIDI controller to the MIDI in connection of Deluge while Deluge is powered off then power up the Deluge.
2. Press :key[Shift + Select] to open the settings menu.
3. Navigate to MIDI settings, :key[Turn Select] and navigate to ‘COMMANDS’. Press :key[Select] to open the global MIDI commands.
4. Choose the ‘FILL’ option to map to the external switch / MIDI device.
5. With the option in-focus press :key[Select] and the :key[LearnInput] button will blink indicating it is available for mapping. ‘COMMAND UNASSIGNED’ is displayed if no MIDI note or channel is assigned.
6. Press & hold :key[LearnInput] + press the external MIDI switch.
7. The display will indicate ‘SET’ to show the setup is now mapped.
8. To unmap, :key[Turn Select] when the function setting is in-focus.

</Steps>

### Using the fill option

<Steps>

1. Ensure the configuration settings are set accordingly. For example the [SYNC-SCALING] button set to fill mode. This function can also be configured as a MIDI command.
2. Set the probability for selected notes to fill. Hold :key[Pad + Turn Select] fully counter clockwise to choose ‘FILL’ for the held pad note.
3. Repeat for several notes. Only notes assigned to the ‘FILL’ mode will be played when the [SYNC-SCALING] button is held during playback.
4. Play the pattern.
5. Press & Hold [SYNC-SCALING] to activate the ‘FILL’ defined notes, these will be shown lit blue on the grid pads while the button is held.
6. Release [SYNC-SCALING] to deactivate the ‘FILL’ defined notes. These will not be played in the normal pattern cycle.

</Steps>
