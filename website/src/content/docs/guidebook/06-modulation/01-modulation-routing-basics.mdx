Parameters within Deluge can be connected / patched to modulation sources. Multiple sources may modulate one parameter, and multiple parameters may be modulated by one source.

#### Modulation Source Shortcuts

There are several modulation sources which are available through the nested menu sound editor. They are also directly accessible from the grid.

#### Modulation Amount

The modulation amount resolution is adjustable to 2 decimal points. The default presentation is units and decimals but can be changed in the community features settings. Turning the Horizontal :key[Horizontal] knob will select the digit to change and then :key[Turn Select] to adjust the amount.

### Connecting a synth modulation source to a parameter

<Steps>

1. Press :key[Clip] to select clip view. This is indicated by the clip button illuminated blue.
2. Select synth by pressing :key[Synth] if not already selected. The synth button illuminates red.
3. Press the :key[Shift + Pad] where PAD is the destination parameter to be modulated. Example is LPF : frequency.
4. Press the :key[Shift + Pad] where PAD is the modulation source from the right side grid columns. Example is LFO 1.
5. The two elements are now connected. The source pad flashes white, quickly. The destination flashes white slowly. Multiple sources and destinations can be patched and connected.
6. The display will show the strength of the connection which is the amount of modulation between the two functions. :key[Turn Horizontal] to select the digit to change and then :key[Turn Select] to adjust. Depth can be set to positive or negative values. Non-zero value means a modulation connection exists.
7. Pressing :key[BackUndo] will confirm and exit the option and back up.

</Steps>

#### Modulation Source Nested Menu

The option to use nested menus for modulation patching is also available. The grid will display the same characteristics of flashing destination and source pads when using shortcuts.

### Connecting a synth modulation source to a parameter

<Steps>

1. Press :key[Clip] to select clip view. This is indicated by the clip button illuminated blue.
2. Select synth by pressing :key[Synth] if not already selected. The synth button illuminates red.
3. Press the :key[Select] to enter the sound editor menus.
4. If desired, :key[Turn Select] to highlight and press to select the MOD MATRIX option. This provides a collective view of all modulation connections. Press (Back) to backup and exit this menu function.
5. :key[Turn Select] to select the destination parameter. Example is LPF.
6. Press the :key[Select] to drill down into the menu. Example is LPF : frequency. The pad will flash quickly.
7. When the value is in-focus, press :key[Select] to drill down further into the menu structure and access the modulation options for the parameter in-focus.
8. Modulation options will be available. :key[Turn Select] to scroll and navigate the options. When the selected option, example LFO 1 is in-focus press :key[Select].
9. The display will show the strength of the connection which is the amount of modulation between the two functions. :key[Turn Horizontal] to select the digit to change and then :key[Turn Select] to adjust. Depth can be set to positive or negative values. Non-zero value means a modulation connection exists.
10. A value other than ‘0’ will create a modulation connection and the display parameter. The modulation pad will flash quickly and the parameter destination will flash slowly. Depth can be positive and negative values.

</Steps>

### Deleting a synth modulation connection

<Steps>

1. Press :key[Clip] to select clip view. The clip button illuminates blue.
2. Select synth by pressing :key[Synth] if not already selected. The synth button illuminates red.
3. Select destination and source. Press the :key[Shift + Pad] where PAD is the destination parameter. Example is LPF : frequency.
4. Press the :key[Shift + Pad] where PAD is the modulation source. Example is LFO 1. Pads will flash and display shows connection.

</Steps>

Or

<Steps>

1. Use nested menu option to select destination parameter. :key[Turn Select] to select the destination parameter. Example is LPF.
2. Press the :key[Select] to drill down into the menu. Example is LPF : frequency. The pad will flash quickly
3. When the value is in-focus, press :key[Select] to drill down further into the menu structure and access the modulation options for the parameter in focus.
4. Modulation options will be available. :key[Turn Select] to scroll and navigate the options. When the selected option, example LFO 1 is in-focus press :key[Select].

</Steps>

Then

<Steps>

1. The display will show the strength of the connection which is the amount of modulation between the two functions. :key[Turn Select] to adjust and set to ‘0’. If required, :key[Turn Horizontal] to select the digit to edit.
2. Pressing :key[BackUndo] will confirm and exit the option and back up.

</Steps>

### Viewing the active modulation list

<Steps>

1. Press :key[Clip] to select clip view. The clip button illuminates blue.
2. Select synth by pressing :key[Synth] if not already selected. The synth button illuminates red.
3. Press :key[Select] to drill down into the nested sound menu.
4. :key[Turn Select] to scroll and navigate the options. When the MOD MATRIX option is highlighted, press :key[Select].
5. The active modulation list is presented which shows the Source, Amount and Destination.
6. Press :key[Select] when highlighting any modulation configuration in the list to open the modulation connection editor.

</Steps>
