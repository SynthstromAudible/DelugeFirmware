Parameters within Deluge can be connected / patched to modulation sources. Multiple sources may modulate one parameter, and multiple parameters may be modulated by one source.

#### Modulation Source Shortcuts

There are several modulation sources which are available through the nested menu sound editor. They are also directly accessible from the grid.

When a parameter is selected which is already patched to a source, the specific source grid buttons will flash slowly. The selected parameter pad will flash quickly.

:key[Shift + Modulation Pad] while the source is selected and flashing will select the DEPTH parameter to enable editing of the modulation strength between modulator and destination parameter.

<StepFocus />

### Connecting a synth modulation source to a parameter

<Steps>

1. Press :key[Clip] to select clip view. This is indicated by the clip button illuminated blue.
2. Select synth by pressing :key[Synth] if not already selected. The synth button illuminates red.
3. Press the :key[Shift + Pad] where PAD is the destination parameter to be modulated. Example is LPF : frequency.
4. Press the :key[Shift + Pad] where PAD is the modulation source from the right side grid columns. Example is LFO 1.
5. The two elements are now connected. The source pad flashes white, quickly. The destination flashes white slowly. Multiple sources and destinations can be patched and connected.
6. The display will show the strength of the connection which is the amount of modulation between the two functions. :key[Turn Select] to adjust. Depth can be positive and negative values. Non-zero value means a modulation connection exists.
7. Pressing :key[BackUndo] will confirm and exit the option and back up.

</Steps>

#### Modulation Source Nested Menu

The option to use nested menus for modulation patching is also available. The grid will display the same characteristics of flashing destination and source pads when using shortcuts.

### Connecting a synth modulation source to a parameter

<Steps>

1. Press :key[Clip] to select clip view. This is indicated by the clip button illuminated blue.
2. Select synth by pressing :key[Synth] if not already selected. The synth button illuminates red.
3. Press the :key[Select] to enter the sound editor menus.
4. :key[Turn Select] to select the destination parameter. Example is LPF.
5. Press the :key[Select] to drill down into the menu. Example is LPF : frequency. The pad will flash quickly.
6. When the value is in-focus, press :key[Select] to drill down further into the menu structure and access the modulation options for the parameter in-focus.
7. Modulation options will be available. :key[Turn Select] to scroll and navigate the options. When the selected option, example LFO 1 is in-focus press :key[Select].
8. The display will show the strength of the connection which is the amount of modulation between the two functions. :key[Turn Select] to adjust.
9. A value other than ‘0’ will create a modulation connection and the display parameter. The modulation pad will flash quickly and the parameter destination will flash slowly. Depth can be positive and negative values.

</Steps>

### Deleting a synth modulation connection

<Steps>

1. Press :key[Clip] to select clip view. The clip button illuminates blue.
2. Select synth by pressing :key[Synth] if not already selected. The synth button illuminates red.
3. Select destination and source. Press the :key[Shift + Pad] where PAD is the destination parameter. Example is LPF : frequency.
4. Press the :key[Shift + Pad] where PAD is the modulation source. Example is LFO 1. Pads will flash and display shows connection.

</Steps>

Or

<Steps>

1. Use nested menu option to select destination parameter. :key[Turn Select] to select the destination parameter. Example is LPF.
2. Press the :key[Select] to drill down into the menu. Example is LPF : frequency. The pad will flash quickly
3. When the value is in-focus, press :key[Select] to drill down further into the menu structure and access the modulation options for the parameter in focus.
4. Modulation options will be available. :key[Turn Select] to scroll and navigate the options. When the selected option, example LFO 1 is in-focus press :key[Select].

</Steps>

Then

<Steps>

1. The display will show the strength of the connection which is the amount of modulation between the two functions. :key[Turn Select] to adjust and set to ‘0’.
2. Pressing :key[BackUndo] will confirm and exit the option and back up.

</Steps>
