Multiple sources can modulate multiple parameters. In addition, modulation sources can also modulate other modulators creating complex and advanced patching systems. The same methodology applies in connecting parameters but must start with the destination. The modulation depth is where to drill down to further modulation options. Pads will flash showing the routing based on the selected in focus parameter.

#### Example 1:

LFO 2 modulates LFO 1 to modulate LPF : frequency cutoff.
