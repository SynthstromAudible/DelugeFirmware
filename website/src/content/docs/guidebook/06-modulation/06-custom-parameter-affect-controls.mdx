### Assigning custom control parameters

<Steps>

1. Press [CUSTOM X] where x is one of the custom buttons 1, 2 or 3. Custom 1 & 3 are under the lower rotary control and custom 2 upper control.
2. Access the sound editor by pressing :key[Select]. Navigate to a parameter to assign. Example : pan
3. When the desired parameter is in-focus, press & hold :key[LearnInput + Turn Upper Gold] or :key[Lower Gold] - the rotary which is assigned to the custom control in step 1.
4. The screen will display ‘LEARNED’ to indicate parameter assignment. Parameter is assigned for the specific function.
5. Unassignment is performed by reassigning the parameter control.

</Steps>

### Assigning user parameters to existing controls

<Steps>

1. Press the desired parameter control button to change, for example :key[LevelPan].
2. Access the sound editor by pressing :key[Select]. Navigate to a parameter to assign. Example : OSCILLATOR 1 &gt; LEVEL
3. When the desired parameter is in-focus, press & hold :key[LearnInput + Turn Upper Gold] or :key[Lower Gold] - the rotary assigned to selection in step 1
4. The screen will display ‘LEARNED’ to indicate parameter assignment. Parameter is assigned for the specific function.
5. Unassignment is performed by reassigning the parameter control.

</Steps>

:::note
MIDI controller controls are also assigned using the same process. MIDI Controls can also be unassigned by navigating to the parameter and by then press and hold :key[Shift + LearnInput].
:::

### Assigning controls to modulation depth

<Steps>

1. Press the desired parameter control button to change, for example :key[StutterCustom1].
2. Access the modulation connection patching by pressing :key[Shift] + Modulation Destination. Press :key[Select] to drill down to the modulation depth parameter.
3. When the desired parameter is in focus, press & hold :key[LearnInput + Turn Upper Gold] or :key[Lower Gold] - the rotary which is assigned to the parameter selected in step 1.
4. The screen will display ‘LEARNED’ to indicate parameter assignment. Parameter is assigned for the specific function.
5. Unassignment is performed by reassigning the parameter control. +

</Steps>
