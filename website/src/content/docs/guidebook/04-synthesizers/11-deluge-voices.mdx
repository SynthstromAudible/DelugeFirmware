A voice can be explained as a single signal path used by synthesizers, and is closely related to a synth’s polyphony. Generally speaking the number of notes played simultaneously would count for the number of voices - although modes such as arpeggiation override how voices are assigned, and unison will sound multiple voices per note. Deluge’s maximum voice count relies on the CPU loading and processing power available, but around 64 is the limit for most basic synth sounds.

### Setting the synth polyphony

<Steps>

1. Press :key[Clip] to select clip view. This is indicated by the clip button illuminated blue.
2. Select synth by pressing :key[Synth] if not already selected. The synth button illuminates red.
3. Using the shortcut option press :key[Shift + Polyphony Pad]. Alternatively use nested menus by pressing :key[Select] and then turning :key[Select] to navigate to POLYPHONY sub-menu option within the VOICE menu. Options are:
   - POLYPHONY : Can play multiple notes simultaneously such as when playing chords and complex arpeggios,
   - MONOPHONIC : Set to play single notes, for example bass lines.
   - AUTO : Primarily monophonic but allows chords to be played.
   - LEGATO : Enables multiple notes to play as tied or connected. This is where notes can be played before a previous note is released.
   - CHOKE : Sets up choke groups when using kits to stop playing one sound when another is played. For example hi-hats closed and open wouldn't be played simultaneously in real world scenarios.
4. Select the priority when in polyphonic mode using :key[Shift + Priority Pad] or using nested menu option by pressing :key[Select] and then turning :key[Select] to navigate to PRIORITY sub-menu option within the VOICE menu.
5. Set priority option for the current synth sound to LOW, MEDIUM or HIGH. Deluge will release voices with lower priority first when CPU loading necessitates.
6. Use :key[BackUndo] or tap any grid pad once to exit sub-menu and back up a level or to back out of the sound editor.

</Steps>

#### Unison Mode

Unison mode enables a number of voices to be triggered by one note. By detuning these voices, rich and thick chorus-like sounds can be created.

### Setting the synth unison

<Steps>

1. Press :key[Clip] to select clip view. This is indicated by the clip button illuminated blue.
2. Select synth by pressing :key[Synth] if not already selected. The synth button illuminates red.
3. Using the shortcut option press :key[Shift + Number Pad] in the UNISON section. Alternatively use nested menus by pressing :key[Select] and then turning :key[Select] to navigate to UNISON sub-menu option within the VOICE menu.
4. Adjust the UNISON NUMBER parameter by turning :key[Select]. Unison number : Number of voices, up to a maximum of 8, played simultaneously when one note is played.
5. Using the shortcut option press :key[Shift + Detune Pad] in the UNISON section. Alternatively use nested menus by pressing :key[Select] and then turning :key[Select] to navigate to UNISON DETUNE sub-menu option within the VOICE menu.
6. Adjust UNISON DETUNE parameter by turning :key[Select]. A value between 0-50 that adjusts and detunes the voices from the original note giving a lush chorus style effect and thickens individual notes.
7. The audition pads can be used to listen in to the sound as it takes shape and also multiple notes can be played as chords on these pads.
8. Use :key[BackUndo] or tap any grid pad once to exit sub-menu and back up a level or to back out of the sound editor.

</Steps>
