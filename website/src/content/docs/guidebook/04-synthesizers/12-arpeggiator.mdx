Each synth clip contains an arpeggiator. The arp settings are contained in the voice section of the sound editor parameters. An arp automatically steps through a sequence of notes and across octaves in a pre-defined way. By default the arp is off for most factory synth presets, and new synth instruments created.

### Setting the arpeggiator

1. Press :key[Clip] to select clip view. This is indicated by the clip button illuminated blue.
2. Select synth by pressing :key[Synth] if not already selected. The synth button illuminates red.
3. Using the shortcut options to access the arp parameters directly, e.g. press :key[Shift + Mode Pad]. Alternatively use nested menus by pressing :key[Select] and then turning :key[Select] to navigate to Arpeggiator sub- menu option within the VOICE menu. Options via the menu or directly from the :key[Shift] + shortcuts are:
   - MODE : pattern style: up, down, both, random or off for arpeggios.
   - SYNC : Sets the time interval of the sync for the arpeggiator or OFF to deactivate tempo sync. Options are 2 bar, 1 bar, 2nd notes, 4th notes, 8th notes, 16th notes, 32nd ,64th notes and 128th notes. (384th Resolution)
   - NUMBER OF OCTAVES : Sets the range of the arpeggiator notes.
   - GATE : Sets the percentage that the note trigger will fill with respect to the available time divisions.
   - RATE : Sets the arpeggiator rate when sync is off.
4. Ensure any sequence timing and steps are taken into account when setting the arpeggiator sync and gate.
5. Use :key[BackUndo] or tap any grid pad once to exit sub-menu and back up a level or to back out of the sound editor.
