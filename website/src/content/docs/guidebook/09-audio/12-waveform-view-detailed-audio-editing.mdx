Audio samples and clips can be displayed and edited on the grid in clip view as a graphical waveform. Waveform editor :key[Shift + Waveform Pad] is a tool for more precise editing. Quick editing will be able to cover some basic functions but a more in depth precise method is provided within the waveform view. Editing functions are available from the shortcut or the nested menus.

#### Waveform Editor

Samples and audio clips can be displayed on the grid as a graphical waveform with editing options. The audio length, unlike the quick waveform editor, does not represent the timing of the sample with reference to the grid. Press :key[Shift + Waveform Pad]. :key[Turn Horizontal] to scroll waveform and press & :key[Turn Horizontal] to zoom.

### Waveform editing length with start & end points

Audio clip length is tied to the song’s tempo - e.g. “1 bar long” - and will not change. So, changing these waveform start and end points or tempo is likely to cause the waveform to be time-stretched when played.

<Steps>

1. With the audio clip in-focus i.e. after recording or loading.
2. Press :key[Shift + Waveform Pad].
3. Grid will show audio in graphical form indicated by white pads.
4. The START position is indicated with a green column.
5. The END position is indicated with a red column.
6. To adjust start or end, press the START or END column :key[Pad] to select it - column flashes. Press a new location :key[Pad] to move the position to.
7. Display will indicate the position of the selected marker.
8. :key[BackUndo] to exit waveform editor.

</Steps>

### ‘grabbing tempo’ to avoid time-stretching

Audio clip length is tied to the song’s tempo and as such will be time-stretched when adjusting markers. Grabbing the tempo of an audio clip will avoid time-stretching.

<Steps>

1. Within :key[Clip] view, press :key[Tempo + Pad] on the grid.
2. Within :key[Song] view, press :key[Tempo + Pad] on the clip’s row. This may be useful when loading an existing audio file into an audio clip and wishing to set the song to its tempo, or to return to the original tempo at which the clips were recorded if the tempo has since been changed, or after minor edits to an audio clip’s waveform’s start and end points (see previous section).

</Steps>

:::note
When working with the markers it is recommended to start with the end marker adjustment first. Zoom out to work at a wider level and zoom in as finer adjustments are needed.
:::

### Adding / locating waveform loop markers

Loop markers can be set for samples but not audio clips.

<Steps>

1. With the sample in-focus i.e. kit sample.
2. Press :key[Shift + Waveform Pad].
3. Grid will show audio in graphical form indicated by white pads.
4. To create a LOOP START, press & hold :key[Pad] for the green start column + press :key[Pad] for column to locate the LOOP START marker. Marker for loop start is illuminated blue.
5. To create a LOOP END, press & hold :key[Pad] for the red end column + press :key[Pad] for column to locate the LOOP END marker. Marker for loop end is illuminated magenta.
6. Play sample, for example press :key[Audition Pad] for the kit row sample in-focus.
7. Sample will play from START, then RESTART at LOOP END (or END if no loop exists) and then play a loop beginning at LOOP start.

</Steps>

### Deleting waveform loop markers

Loop markers can be set for samples but not audio clips.

<Steps>

1. With the sample in-focus i.e. kit sample.
2. Press :key[Shift + Waveform Pad].
3. Grid will show audio in graphical form indicated by white pads. Loop markers will be blue and magenta columns.
4. To delete LOOP START marker, press & hold :key[Pad] for the green start column + press :key[Pad] for LOOP START column.
5. To delete LOOP END, press & hold :key[Pad] for the red end column + press :key[Pad] for LOOP END column.

</Steps>
