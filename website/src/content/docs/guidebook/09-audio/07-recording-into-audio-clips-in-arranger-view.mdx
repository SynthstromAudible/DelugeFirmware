Audio can be also be recorded in arranger view, which provides more structure and arrangement functionality. Ensure audio clips have already been created.

### Creating an audio clip in arranger view

1. Press :key[Song] to switch to song view and press :key[Song] again for arranger view. Button flashes blue.
2. Press & hold a :key[Audition Pad] Pad. This can be either an existing or blank row. The instrument button will flash indicating the type selected and display will show the preset or MIDI/CV Channel.
3. While still holding the audition pad, press :key[Select].
4. The track will be converted to an audio clip and the display will show the name, example: ‘AUDIO1’. If converting an instrument track, ‘CANT’ is displayed if notes exist and the track wont be converted.
5. Selecting the audio clip will then allow audio to be loaded, recorded, edited, etc.

### Selecting the audio in

1. Press :key[Song] and :key[Song] to switch to arranger view.
2. Press & hold :key[LearnInput + Audition Pad] of a selected audio clip row to record into.
3. :key[Turn Select] to change to the input desired. This should match the physical connection. Example, a mono input would typically be the LEFT input, with LEFT. for input monitoring.
4. If input monitoring is required a dot . version of the left, right, stereo, balanced inputs is available for thru audio monitoring.
5. Display will indicate the selected channel input for the track on which the clip sits.
6. Exit this setting before recording by pressing :key[Select], :key[Back], or any :key[Pad]

### Arming audio tracks for recording in arranger mode

1. Press :key[Song] and :key[Song] again to switch to arranger view.
2. Tracks will be disarmed by default.
3. Press & hold :key[Record] to see each tracks status.
   - Armed rows - :key[Mute Pad] pads illuminate flashing red. Tracks will record audio.
   - Semi-armed rows - :key[Mute Pad] pads flashes dim grey-red. Semi-armed meaning armed in theory but wont record as the tracks already contain audio
   - Unarmed clip rows - :key[Mute Pad] pads lit dimly coloured. Track is empty and can be recorded into but only when armed.
4. Press :key[Record + Mute Pad] to arm or disarm any track row.

### Recording an audio clip in arrangement view

1. Press :key[Song] and :key[Song] to switch to arranger view. Ensure audio input is set and tracks are armed. :key[Record] should be lit.
2. Press :key[Play]. Recording will start. Play and record buttons will be lit. All armed tracks will record.
3. The red recording cursor will travel left to right across the clips being recorded.
4. Recording will take place into newly created clip-instances, unless a clip already exists.
5. Recording will be continuous and not be limited by any length. Length is set only when previously recorded or existing audio exists when recording within a clip.
6. Press :key[Record] to stop recording, play continues to end of clip.
