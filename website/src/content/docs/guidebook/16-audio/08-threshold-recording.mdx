## The threshold recording screen <Badge text="C1.4" variant="tip" />

On OLED, recording with a threshold shows a level meter for the left (L) and right (R) inputs, so it's easy to see how close the signal is to starting the recording.

- While waiting, the screen shows WAITING... and a blinking dotted line on the meter marks the threshold level. Recording starts when the input crosses it.
- Once recording starts, the screen shows RECORDING with a blinking record dot, and the meter stays up for the rest of the take.
- A dotted line near the right-hand end of the meter marks where the input is getting loud. If either input goes past it, a ! warns that the level may be too high.
