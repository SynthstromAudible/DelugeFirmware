Playback of audio can be reversed and also played back in several in several modes:

    - ONCE. The sample plays once, always the whole way through. Good for drum samples and short ‘hits’. Samples shorter than two seconds will by default be set to ONCE, to behave as a one-shot sample: any time the sample is triggered, the whole sample will play.
    - CUT. The sample plays once, but may be cut short at the end of the “note” triggering the sound. Samples longer than two seconds will be set to CUT mode, to play only as long as the user is holding down the row’s audition pad - or as long as a sequenced note is sounding on that row.
    - LOOP. The sample loops indefinitely until the “note” ends.
    - STRETCH. The sample is time-stretched to the length of the note. Good for samples that contain pre-made beats.

Some .wav and .aiff files contain tags specifying sample loop points. The Deluge will read these if they are present. See waveform view for more info.

## Reversing playback

<Steps>

1. With a synth type set to sample and a file loaded and in-focus use shortcuts :key[Shift + Reverse Pad] for sample 1 or sound editor - :key[Select] &gt; OSCILLATOR 1 &gt; REVERSE.
2. :key[Turn Select] to adjust ‘REVERSE’ - reverse between on and off. ON meaning the audio is reversed.

</Steps>

## Setting playback mode

<Steps>

1. With a synth type set to sample and a file loaded and in focus use shortcuts :key[Shift + Mode Pad] for sample 1 or sound editor - :key[Select] &gt; OSCILLATOR 1 &gt; ‘REPEAT MODE’.
2. :key[Turn Select] to adjust. The options are ‘ONCE’, ‘LOOP’, ‘STRETCH’, ‘CUT’.

</Steps>

## Smoothing loops with a crossfade <Badge text="C1.4" variant="tip" />

Loops whose start and end don't join up perfectly can click or bump each time they go round. LOOP XFADE fades the end of the loop out while the start of the next pass fades in, so the join is smooth.

<Steps>

1. With a synth type set to sample and a file loaded and in focus, open the sound editor - :key[Select] &gt; OSCILLATOR 1 (or 2) &gt; LOOP XFADE, just after REPEAT MODE.
2. :key[Turn Select] to set the crossfade time, from OFF up to 1000 ms in 10 ms steps. Longer crossfades smooth out more difficult joins.

</Steps>

- The crossfade works whenever the sample loops: in LOOP mode, or with a loop end point while the note is held, playing forwards or reversed. With no loop points set, the whole sample is the loop.
- The crossfade can be at most half the loop's length.
- The time is measured in the sample's own time, so the crossfade gets shorter as the sample is played higher.
- It needs PITCH/SPEED linked and SPEED at 0. Otherwise notes away from the sample's own pitch are time-stretched, and the loop jumps as it did before.
