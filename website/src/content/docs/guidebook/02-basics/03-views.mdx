There are four main views which presents the user environment and toolkit for specific functions. Clip view concentrates on individual instruments, MIDI, CV, audio and their associated sequences. Session view is where a collection of clips are managed into a full song. Arranger enables the chaining of clips to develop a longer, linear arrangement. The fourth view is keyboard view, utilizing the grid as a live melodic instrument.
