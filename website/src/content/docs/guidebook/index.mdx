This is the official Deluge Guidebook for OS 4.1 — "more than just a manual: guidebook,
reference, notebook" — converted from the printed PDF into searchable, linkable pages.

It describes the **official 4.1 firmware**. Community firmware has changed and added a
lot since then; where a page here disagrees with the community documentation, the
community documentation describes current behaviour.
