This is the Deluge Manual by Synthdawg, converted into searchable, linkable pages. The source for
this website is the second draft of the edition for **community firmware C1.0.0**.

Community firmware has changed and added more since C1.0.0; where a page here disagrees with the
community documentation, the community documentation describes current behaviour. [Appendix E](/guidebook/appendix/e-community-guide-os-41) is
still the OS 4.1 Guidebook's community guide until it is converted from this edition.

ATTRIBUTION — All text and graphics originally created by Synthdawg.
