While a kit can contain drum and synth sounds it is normally recognised that kits are typically associated with drum kits. An alternate view presents the grid layout as MPC style drum pad zones using KEYBOARD when in KIT mode.

### Selecting grid pad view

<Steps>

1. Press :key[Clip] to select clip view. Clip button illuminates blue.
2. Press :key[Kit], the button will be lit red.
3. Press :key[Keyboard], the button will be lit blue,
4. The grid will be presented in a colour coded drum pad style with 8 zones, each configured with 4 x 4 pads.
5. To scroll the kit pad zones one at a time, :key[Turn Horizontal].
6. To jump vertically the kit pad zones, :key[Turn Vertical].
7. Tap a pad zone to play one of the 8 sounds. The 16 levels of velocity run from lowest velocity is bottom left pad and increases to the right and up the grid to the highest level top left. Each pad zone plays a kit sound, each pad within the zone represents the sound velocity level.

</Steps>
