Loop recording carries a specific workflow and a foot controller when recording and playing loops especially live is a useful accessory. Guitarists for example can control the loop recording while concentrating hands-on with their guitar. Global MIDI commands provide an easy interface between Deluge and a MIDI foot switch.

### Setting up an external foot controller for looping

1. Connect the foot switch to the MIDI in connection of Deluge while Deluge is powered off.
2. Power up the Deluge.
3. Press :key[Shift + Select] to open the settings menu.
4. Navigate to MIDI settings, :key[Turn Select] and navigate to ‘COMMANDS’.
5. With ‘COMMANDS’ in-focus, press :key[Select] to open the global MIDI command menu options.
6. Choose the option to map to the external switch: Example: switch 1 = loop, switch 2 = layer, switch 3 = play, switch 4 = undo. This will be dependant on the device connected and number of switches.
7. With the option in-focus press :key[Select] and the :key[LearnInput] button will blink indicating it is available for mapping. ‘NONE’ is displayed if no MIDI note or channel is currently assigned.
8. Press & hold :key[LearnInput] and press the associated switch on the external MIDI foot controller.
9. The display will indicate ‘SET’ to show the setup is now complete and the switch is mapped to the specific function.
10. To unmap the command, :key[Turn Select] when the function setting is in- focus or set it to a new input.

#### LOOP v LAYER Global Commands
