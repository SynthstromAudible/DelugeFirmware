As well as samples, sounds and synths, CV can also be combined within a kit as a row providing a note output to a CV channel. CV sequencing can then take place alongside other kit sounds. Also independent control of gate channels is possible within kits for CV.

### Creating / converting to CV clips within kits

1. Select :key[Clip] view and select :key[Kit].
2. Press & hold :key[Audition Pad] for the row which will convert to CV + press :key[CV].
3. Hold :key[Audition Pad] for the CV row to display the gate channel information.

<FigurePending id="fig-13.5-1" page={272}>
  GATE CHANNEL 3 · Gate Channel Example: 3 from a range of 1-4
</FigurePending>

4. While holding the audition pad, :key[Turn Lower Gold] control to change the gate channel. This process allows independent setting of gate channels.
5. :key[Kit + Save] to save the kit and retain the CV setting.

### Changing clip CV channel within song view

1. Select :key[Song] view.
2. Press & hold :key[Pad] for the CV clip row to change + :key[Turn Select] to change channel 1-2.
3. CV button will flash while holding and display will show the current channel.
