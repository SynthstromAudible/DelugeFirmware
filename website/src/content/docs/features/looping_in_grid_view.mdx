## Description

There are two different looping techniques that can be used in the new Song Grid View:

1. Using green mode, create and immediately arm a clip within an existing track for recording
2. Select an existing clip :key[PAD] and use the Global MIDI Commands: `LOOP` and `LAYERING LOOP `

The above techniques are described below

To use the technique shown in the video above, you must follow these steps:

- Enable Create + Record:
  - Enter `SETTINGS > DEFAULTS > UI > SONG > GRID > EMPTY PADS > CREATE + RECORD` and select `ENABLED`
  - Exit Settings menu (:key[BACK]) to save settings

- The following steps enable you to quickly create and arm new clips for recording:
  - In Grid view, make sure you are in Green mode (:key[GREEN AUDITION PAD]).
  - Press :key[PLAY] to start playback and press :key[RECORD] to enable recording.
  - Short-press any empty :key[PAD] in an existing Instrument column to create and arm a new clip for recording
  - The new clip that was just created will be selected and start recording at the beginning of the next bar
  - You can press :key[RECORD] to stop recording or press the `NEW CLIP` :key[PAD] to stop recording.
  - Repeat steps as required.

## Select an existing clip and use the Global MIDI Commands: LOOP and LAYERING LOOP

This technique requires the following:

- you have created a clip
- you have selected that clip by pressing and holding it from grid view or by entering it
- you are able to use the Global MIDI Commands: `LOOP` or `LAYERING LOOP` by either using the Grid Loop/Layering Loop pads or by sending the Loop/Layering Loop Global MIDI Commands using an external controller.

To enable the Grid Loop/Layering Loop pads (<Badge text="c1.2 Feature" variant="tip" />), enable `Grid View Loop Pads (LOOP)` in the `Community Features menu`.

- When On, two pads (:key[Red Audition Pad] and :key[Magenta Audition Pad]) in the GRID VIEW sidebar will be illuminated and enable you to trigger the LOOP (Red) and LAYERING LOOP (Magenta) global MIDI commands to make it easier for you to loop in GRID VIEW without a MIDI controller.

After you have setup the above, you can now use the LOOP/LAYERING LOOP global MIDI commands in grid view.

This video demonstrates using the Magenta LAYERING LOOP pad in grid view which will continuously create a new audio clip in a new track until you stop it.

## Record successive takes on one track

Learn `Loop Take` (`LOOP_TAKE`) or `Layering Loop Take` (`LOOP_CONTINUOUS_LAYERING_TAKE`) under `SETTINGS > MIDI > COMMANDS`.

You can also enable `Grid View Loop Pads (LOOP)` in the Community Features menu and use the bottom two pads in the right sidebar:

- **Orange**, second from bottom: Loop Take.
- **Cyan**, bottom: Layering Loop Take.

These pads brighten while pressed and are below the existing red Loop and magenta Layering Loop pads.

Select an audio, synth, kit, MIDI, or CV clip by holding its pad in Grid View or entering the clip. The clip must be armed for recording; audio clips also need an audio input, as with the existing loop commands.

- **Loop Take** follows the Loop command's start/stop workflow and records one take with a length you determine by ending the recording.
- **Layering Loop Take** follows the Layering Loop workflow and repeatedly records new takes of the source clip's length. Trigger the command again to cancel the pending next take and end continuous recording.

Each new take occupies the first unused section on the selected track: a new pad in the same column. Starting the next take stops the previous clip on that track. Clips on other tracks can still provide accompaniment.

Takes always create fresh clips, including when the track is set to overdub in place. Once all 24 sections on that track are occupied, no further take is created and a message appears; existing clips are preserved. Free a section to record more takes. The original Loop and Layering Loop commands and their Grid View sidebar pads keep their behavior, except for the changes below.

### Notes for all loop commands

- Loop commands can't create new clips while any clip is soloed. A `Can't create overdub while clips soloing` message (`SOLO` on 7-segment displays) appears. Stop soloing and try again.
- If a loop command can't create a clip (for example because clips are soloed, all sections are full, or there isn't enough memory), it no longer turns on `RECORD`.
- Continuous layering only continues for recordings started by `Layering Loop`, `Layering Loop Take`, or :key[Record + Section Pad] on a clip in Song Row View. Launching a previously layered clip by hand with `RECORD` on records it once, without starting a new chain of layers.
