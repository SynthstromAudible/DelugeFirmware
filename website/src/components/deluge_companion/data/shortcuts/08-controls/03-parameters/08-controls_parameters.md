# Assign gold dial control of parameters - first select parameter

#OFFICIAL #SYNTH #KIT

```shortcut
hold(LEARN) + turn(PARAMETER)
```

More assignable options are available through the sound editor. Make sure the parameter itself, not just its category, is selected.

# Check gold dial control of parameters - first select parameter

#OFFICIAL #COMMUNITY #SYNTH #KIT

```shortcut
turn(PARAMETER)
```

Check the LCD screen for parameter variation when selected and adjusted.

```community
In the community firmware, turning a gold dial will display the name of the parameter it controls in addition to the current value on the OLED display.
```

# Cycle parameter assignment to gold dial between LPF, HPF, and EQ

#OFFICIAL

```shortcut
press(PARAMBUTTON2), press(UPPER_PARAM)
```

Select Cutoff / Res parameter bank. Press upper gold dial to toggle between LPF, HPF and EQ.

# Change LPF or HPF mode depending on parameter assignment to gold dial

#OFFICIAL

```shortcut
press(PARAMBUTTON2), press(LOWER_PARAM)
```

Select Cutoff / Res parameter bank. Press lower gold dial when parameter bank is set to LPF or HPF to cycle between LPF or HPF modes.

# Delete automation of tempo

#COMMUNITY #ARRANGER

```shortcut
press(SHIFT) + press(TEMPO)
```

# Copy automation of parameter

#OFFICIAL #SYNTH #KIT

```shortcut
hold(LEARN) + press(PARAMETER)
```

Automation is copied one parameter at a time at the current zoom level. You can copy between parameters, clips, and songs.

# Paste automation of parameter

#OFFICIAL #SYNTH #KIT

```shortcut
hold(SHIFT) + hold(LEARN) + press(PARAMETER)
```

Press Select to cancel section switching during countdown.

# Parameter change / lock per note in clip view

#OFFICIAL #CLIP

```shortcut
hold(GRID_LIT) + turn(PARAMETER)
```

Press any column pad to set the automation value manually between 0 on the bottom pad and 127 on the top pad. Hold a column pad to adjust automation values.

# Parameter change / lock per clip in session view or arranger view

#OFFICIAL #ARRANGER #SESSION

```shortcut
hold(GRID_LIT) + turn(PARAMETER)
```

Changes or locks the selected parameter per clip in Session View.

# FX Toggle Options - Upper Gold Knob

#OFFICIAL #SYNTH #KIT #ARRANGER #SESSION

```shortcut
press(UPPER_PARAM)
```

When the relevant parameter is selected, this toggles the upper FX option blocks such as LP/HP/EQ mode, Ping-Pong, compressor sync, effect type, or stutter mode.

# FX Toggle Options - Lower Gold Knob

#OFFICIAL #SYNTH #KIT #ARRANGER #SESSION

```shortcut
press(LOWER_PARAM)
```

When the relevant parameter is selected, this toggles the paired lower FX option blocks such as slope type, delay style, room size, effect depth/offset/feedback, or stutter ramp speed.

# Momentary stutter

#OFFICIAL

```shortcut
press(PARAMBUTTON7), hold(UPPER_PARAM)
```

Select stutter parameter bank and hold down upper gold dial to engage stutter.

# Momentary stutter and adjust stutter rate

#OFFICIAL

```shortcut
press(PARAMBUTTON7), press(UPPER_PARAM) + turn(UPPER_PARAM)
```

Select stutter parameter bank and hold down upper gold dial to engage stutter. Turn upper gold dial while stutter is engaged to change stutter rate at same time as stutter.

# Delete Parameter Automation from Sound Editor Menu

#OFFICIAL #MENU #MENU_SOUND

```shortcut
hold(SHIFT) + press(SELECT)
```

While in the sound editor menu for an automatable parameter, hold shift and press select to delete automation for the selected parameter.
