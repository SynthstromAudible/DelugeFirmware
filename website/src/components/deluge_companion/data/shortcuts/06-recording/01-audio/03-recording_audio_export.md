# Start Audio Export

#COMMUNITY #ARRANGER #SESSION #KIT

```shortcut
press(SAVE) + press(RECORD)
```

Starts audio export from Session/Arranger, or Kit drum export when you are in Kit Instrument Clip View.

# Cancel Audio Export

#COMMUNITY #ARRANGER #SESSION #KIT

```shortcut
press(BACK), press(SELECT)
```

Press BACK while audio export process is running and then press SELECT to confirm.
